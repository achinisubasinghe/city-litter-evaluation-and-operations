There are soo many litter left behind roads where everybody misses those which stays there for months. Due to this issue spreading 
various vector diseases like dengue and breeding mosquitos, etc can be caused. In Sri Lanka there are Local Authorities like Pradeshiya Sabha, Nagara Sabha and Municipal councils where they have assigned pepole to collect these litter behind the roads. There are public and private sector cooperations and various ways they used to bring a solution for this issue. In public sector they assign the employees
uder the cooperation to collect the litter using trucks with a schdeule and a specific fixed route. In private sector they assigned 
workers to clean those by going to those places when citizen reports them manually other than working on relavant schedules. Currently 
there is no efficient way to identify, report and track these actions like illegal dumped litter lest behind the streets. So i wanna 
bring the solution CLEO:Clean Living Environment Observer which is full system where it automatically or through a crowd sourcing web 
application/whatsapp chat bot detects the places where litter is left and reporting automatically to a dashboard where local authorities can access and assign those to the garbage collecting workers. Workers can access the specific task using a mobile application. I am 
building a edge computing based hardware device which contains Raspberry Pi 4B with Camera, NEO-6M GPS, MPU-6050 IMU, ONNX inference 
engine, and SQLite offline-to-cloud sync service where it can automatically detects the locations where missing litter left in the routes truck move. Once the trucks return to the parking destination the device should connected to the network connection automatically and upload the data to the server. Binary image classification model is tarined to detect if the image is litter or not. Its running inside the raspberry pi and also its used for the crowed source web application/chatbot to identify whether the image send by the user is a 
litter containing image or not. If its containing litter it requests it's location and stores in the server the relavant data and passed to the dashboard where local authorities can track those locations and assign the relavant workers. This solution will help to build 
clean cities which help to achieve SDG goal 11 which is "Sustainable Cities and Communities" specifically targets the 11.6.
